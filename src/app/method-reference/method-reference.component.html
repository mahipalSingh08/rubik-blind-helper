📖 OP & M2 Methods Reference

Core algorithms and logic for solving blindfolded

Old Pochmann (OP) for Corners

Buffer: UBL (Up-Back-Left)

Target: RFD (Right-Front-Down)

Core Algorithm (Y-Perm): R U' R' U' R U R' F' R U R' U' R' F R

How it works: The Y-Perm swaps the UBL and RFD corners (while also swapping the UB and UL edges, which is why parity matters). For any target letter, you execute a setup move to place that sticker at RFD, do the Y-Perm, and then undo the setup move.

M2 for Edges

Buffer: DF (Down-Front)

Target: UB (Up-Back)

Core Algorithm: M2

How it works: M2 swaps DF and UB. Similar to OP, you setup the target sticker to UB, do M2, and undo the setup. Because M2 is a slice move, doing it an odd number of times leaves the M-slice centers off by 180°. This means the rules for M-slice targets (UF, UB, DF, DB) change depending on whether it's an odd or even target.

Special M-Slice Algorithms (Odd Targets)

  • UB (C): U2 M' U2 M'
  • UF (I): U2 M' U2 M' (if C was already done) or D M' U R2 U' M U R2 U' D' M2
  • BD (W): M U2 M U2
  • DF (A): Buffer (Should never be a target, break into a new cycle)

Parity

If you have an odd number of edge targets, your M-slice will be off, and your OP corners will have swapped UB/UL. You fix this between edges and corners.

Parity Algorithm (Ra-Perm variant): D' L2 D M2 D' L2 D (assuming you solve Edges then Corners with M2/OP)
